# 확인한 범위와 남은 검토

[처음으로](../README.md)

## 배포 파일 확인

- 최신 배포본 25개 파일, ZIP 약 48.8MB, ZIP 루트에 index.html 포함
- 압축 데이터 해제와 원본 바이트 일치 확인
- HTTP를 통한 세그먼트·박스·프레임 로딩 및 실제 모델 엔진의 그리기 호출 확인
- 내부 페이지 구조, 링크, 키보드 유지·해제, 슬라이더 동기화 검사

그리기 검사는 기록용 WebGL 컨텍스트를 사용했습니다. 실제 브라우저 GPU 화면·실기기 조작 및 실제 Netlify 배포 완료를 의미하지 않습니다.

## 설계 검증 경계

이 모델은 제작 승인 도면이 아닙니다. 열·구조·절연 성능, 단락 전류, 퓨즈 차단용량, 버스바 정격, 공차 및 실제 공구 접근성은 별도 검증이 필요합니다. 차량 체결 방식은 미정입니다.

계산기/제조사 최대 셀 치수 21.6 × 70.2mm와 기존 형상의 21.55 × 70.15mm 사이에는 차이가 있습니다. 제작용 홀더 치수 확정 시 확인해야 합니다.

이전 CAD/STL·부품표는 Git 이력에만 보존했습니다. 최신 웹 모델과 일치하는 제작 도면·BOM은 확정하지 않았습니다.

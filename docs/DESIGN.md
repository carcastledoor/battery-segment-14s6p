## 계산에서 시작한 구성

사용 셀은 Molicel P45B입니다. 셀 데이터와 직·병렬 수를 직접 만든 계산기에 적용해 전압, 용량, 에너지, 셀 개수와 셀 질량을 검토했습니다.

| 항목 | 현재 설계 기준 |
|---|---:|
| 전체 구성 | 70S6P, 420셀 |
| 세그먼트 | 14S6P × 5개 |
| 공칭 / 최대 전압 | 252V / 294V |
| 용량 / 공칭 에너지 | 27Ah / 6.804kWh |
| 셀 질량 합계 | 28.98kg (69g/셀 기준, 케이스·전장품 제외) |

[계산기 원본](../site/documents/battery-pack-calculator.xlsx)의 저장된 입력은 Samsung 50S·24S12P 예시입니다. 위 수치는 P45B·70S6P를 같은 계산 관계에 적용한 값이며 저장된 입력값과 구분해야 합니다. 셀 정격 전류의 병렬 합을 팩의 검증된 허용 전류로 취급하지 않습니다.

## 패키징으로 연결

- 14S6P 세그먼트의 A/B 단자 배치를 이용해 B–A–B–A–B로 배치합니다.
- 셀 연결부는 니켈 용접 패치와 구리 연결판으로 구성하고, V2 끝단은 ㄱ자 일체형 연결 구조입니다.
- 세그먼트 팬 방향을 통일하고, 하부 세그먼트 공간과 상부 전장품 공간을 구분합니다.
- 양극 전력 경로는 세그먼트 → 퓨즈 → AIR+ → 외부 고전압 커넥터입니다. 음극은 AIR−를 거칩니다.
- 센싱 PCB, BMS, 온도 확장모듈, IMD의 배치와 커넥터 접근 공간을 함께 검토합니다.
- 뚜껑의 안·바깥 측벽이 박스 벽을 감싸며, 팝너트는 뚜껑 안쪽 벽에 배치합니다.
- 조립·분해 화면은 정비 동선을 검토하기 위한 표현입니다. 용접·영구 고정부는 독립적으로 분해하지 않습니다.

배터리박스의 차량 체결 방식은 아직 결정하지 않았습니다. 차량 프레임 화면은 참고 형상이며 장착 설계 확정을 뜻하지 않습니다.

셀 상세, 배열 계산식 및 설계 근거는 웹 뷰어의 Description에서도 확인할 수 있습니다.

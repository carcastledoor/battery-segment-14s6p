# 심사위원 검토 안내

## 1. 설계 개요

이 프로젝트는 **14S6P 배터리 세그먼트 5개를 사용한 70S6P 팩의 기계 패키징 초안**입니다. 셀 420개, A/B 교대 단자, 2층 전장 트레이, 구리 버스바, 측면 볼팅 커버의 배치와 분해 구조를 검토했습니다.

## 2. 3D 모델 확인

1. 저장소의 `portfolio/downloads/Interactive-Preview.zip`을 다운로드합니다. 별도로 전달받은 ZIP도 동일하게 사용할 수 있습니다.
2. **압축을 모두 푼 뒤** `index.html`을 Chrome 또는 Edge로 엽니다.
3. **전체 3D 모델 열기**를 선택합니다. 드래그로 회전하고 휠로 확대합니다.
4. 벽 투명도를 높여 내부 배치를 확인하고, 조립·분해 슬라이더를 움직여 뚜껑부터 세그먼트까지의 분해 표시 순서를 확인합니다.
5. 세그먼트 모델에서는 A/B 형식을 바꾸고 부품별 표시를 켜고 끌 수 있습니다.

ZIP 내부의 3D 미리보기와 부품 검색은 인터넷·GitHub 로그인 없이 실행됩니다. 별도 CAD 묶음의 GitHub 다운로드 링크는 저장소 접근 권한이 필요합니다.

## 3. 검토 포인트

| 항목 | 확인할 내용 |
|---|---|
| 교대형 세그먼트 | B–A–B–A–B 단자 위치, 일정한 팬 방향 |
| 전력 경로 | 세그먼트 연결쌍, 퓨즈 후보 외형, AIR와 외부 HV 커넥터 연결 |
| 소자방 | BMS 방향, 온도 모듈 독립 바닥 체결, IMD 3층 공간 |
| 기구 분해 | 먼저 제거한 부품을 위·바깥에 표시, 트레이 인양 전 벽 체결 해제 |
| 뚜껑 | 기존 박스 벽과 외측 겹침벽, 외부 볼트·내측 팝너트 |
| 부품 관리 | 전체 부품표 및 A/B·팩 공용 STL |

## 4. 설계 상태

제작 승인·실차 시험 완료 설계가 아닌 **패키징 검토 초안**입니다. 미확정 부품, 실제 수행한 검사와 미수행 검사는 [DESIGN.md](DESIGN.md) 및 [VALIDATION.md](VALIDATION.md)에 구분했습니다. 분해 애니메이션은 기구 검토 도구이며 고전압 정비 작업 절차가 아닙니다.

## 5. 비공개 자료 열람

저장소는 비공개입니다. 링크만으로는 외부인이 열 수 없으므로 저장소 소유자가 심사위원 계정에 접근 권한을 부여하거나, `Interactive-Preview.zip`을 심사 자료로 직접 전달해야 합니다. 현재 다른 계정 초대나 공개 전환은 하지 않았습니다.

# Formula EV 배터리 · 포트폴리오 근거 자료

제출 포트폴리오 **「AI와 함께 설계한 Formula EV 배터리」**에서 소개한 계산기와 후속 3D 설계 파일입니다. 발표자료의 해당 페이지를 보면서 계산 과정과 실제 설계 산출물을 확인할 수 있습니다.

## 포트폴리오에서 확인할 자료로

| 포트폴리오 | 이 저장소의 자료 | 확인할 내용 |
|---|---|---|
| **7장 · AI 설계 도구** | **[Excel 계산기 다운로드](site/documents/battery-pack-calculator.xlsx)** | 셀 DB 조회, S/P 입력, 전압·용량·에너지·질량·배치 치수 수식 |
| **8장 · 설계안 비교** | **[후보 비교 재현 방법](docs/CALCULATOR.md)** | 24S에서 8P·10P·12P·14P를 대입해 발표자료의 비교값 확인 |
| **17장 · 자연어 기반 3D 설계 확장** | **[모델 확인 안내](docs/VIEWER.md)** · [설계 파일 설명](docs/DESIGN.md) | P45B 세그먼트, 배터리박스, 전장품 배치와 조립·분해 구조 |

**계산기를 먼저 확인하려면:** Excel의 `Battery_Calculator`에서 저장된 Samsung 50S·24S12P 입력과 결과를 확인하세요. 288셀·86.4V·60Ah·5.184kWh가 발표자료의 예시입니다. 8장의 비교는 병렬 수를 바꿔 재현합니다.

**3D 설계를 확인하려면:** 최신 뷰어의 Segment와 Battery Box를 확인하세요. 현재 공개된 실행 주소는 등록되지 않았습니다. [모델 확인 안내](docs/VIEWER.md)에 다운로드와 로컬 실행 방법을 정리했습니다.

## 자료의 범위

계산기는 **2025 실물 프로젝트의 50S·24S12P 설계 탐색**을, 3D 파일은 **17장의 후속 P45B·70S6P 설계 확장**을 뒷받침합니다. 두 설계는 서로 다른 프로젝트 단계입니다.

실물 제작·고장 진단·검차 결과는 포트폴리오 13–16장의 사진과 기록을 참고하세요. 이 저장소의 계산기·후속 모델은 해당 실물 결과를 대신하는 시험 증빙이 아닙니다. [검증 범위](docs/VALIDATION.md)

# AI와 함께 설계하고 실물로 검증한 Formula EV 배터리

SK하이닉스 AI 해커톤 지원 보충자료입니다. 발표자료의 문제 해결 흐름에 따라 계산 도구와 후속 3D 설계를 연결했습니다.

## 검토 순서

1. [발표자료 18장](SK_Hynix_AI_Hackathon_Battery_Portfolio_v39_FinalReviewed.pptx): 2025년 저전압 발견, 재설계, 제작, 고장 진단, 검차 결과를 확인합니다.
2. [Excel 계산기](Formula_Student_Battery_Pack_Calculator_Rebuilt.xlsx): 발표자료 7~8장의 설계 탐색을 수식과 입력값으로 확인합니다.
3. [계산기 검토 안내](CALCULATOR.md): 재현할 입력, 결과, 치수 해석 범위를 확인합니다.
4. [후속 AI-CAD 모델](../index.html): 발표자료 17장의 다음 시즌 설계 확장을 확인합니다. GitHub에서는 HTML을 실행하지 않으므로 미리보기 ZIP을 압축 해제해 여세요.

## 두 프로젝트의 관계

| 구분 | 2025 실물 프로젝트 | 다음 시즌 AI-CAD 확장 |
|---|---|---|
| 자료 | 발표자료 1~16장, 계산기 | 발표자료 17장, 이 저장소 3D 모델 |
| 셀·구성 | Samsung 50S, 24S12P, 288셀 | Molicel P45B, 70S6P, 420셀 |
| 세그먼트 | 4S12P × 6 | 14S6P × 5 |
| 상태 | 발표자료에 제작·차량 통합·2025 배터리 검차 통과 제시 | 형상·배치·분해 검토 초안 |
| AI 활용 | 위험요인 정리, 계산기 제작, 후보 비교, 고장 가설 축소 | 자연어 요구를 3D 형상으로 구현하고 반복 수정 |

2025년 조립·체결 문제를 직접 겪은 경험이 후속 설계의 정비 접근성, 커넥터 탈착, 체결 순서 검토로 이어졌습니다. AI는 반복 계산과 가설 탐색을 도왔고, 설계 선택과 실물 점검은 지원자가 수행했습니다. 과거 결과는 제공된 발표자료에 근거하며, 후속 70S6P 모델의 제작·시험 완료를 의미하지 않습니다.

## 추가자료 설명 문구

발표자료와 함께 AI를 활용해 제작한 Formula Student 배터리 설계 Excel 계산기를 첨부했습니다. 셀 데이터와 직렬·병렬 수를 입력하면 전압, 용량, 에너지, 셀 질량 및 1차 배치 치수를 계산합니다. Samsung 50S 24S12P 예제로 발표자료의 288셀·86.4V·60Ah·5.184kWh 산출 근거를 확인할 수 있습니다. 2025년 실물 제작과 고장 진단에서 얻은 조립·정비 조건을 후속 P45B 70S6P 설계에 반영한 3D 미리보기와 부품표도 포함했습니다. 후속 모델은 배치 검토 초안으로, 기존 검차 통과 프로젝트와 구분했습니다.

## 제출 방식

지원 페이지에서 확인한 조건은 PDF·ZIP·PNG·JPG 중 파일 1개, 최대 50MB입니다. 제출용 ZIP에는 PPT 원본, Excel 원본, 이 안내와 오프라인 3D 미리보기가 들어갑니다. 압축 해제 후 PPT는 PowerPoint, Excel은 Excel, 미리보기는 브라우저로 확인합니다. 저장소는 비공개이므로 지원서에 GitHub 링크만 넣으면 심사위원이 열지 못할 수 있습니다. 첨부 ZIP은 로그인 없이 검토할 수 있습니다.
